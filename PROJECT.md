# El Chambas Landing

## Vision
Una landing pública, clara y memorable para explicar El Chambas y mostrar su video promocional.

## Stack
HTML, CSS y JavaScript vanilla; assets locales; compatible con GitHub Pages y cualquier hosting estático.

## Constraints
No incluir credenciales, datos personales, perfiles, bases de datos ni el backend local.

## Scope v1
Hero, propuesta de valor, flujo en tres pasos, video de 60 segundos, CTA y responsive móvil.
