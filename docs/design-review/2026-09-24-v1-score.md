# Revisión de diseño — El Chambas landing

## Dirección aprobada

**Entender la oferta. Encontrar la evidencia. Postular con criterio.**

La página presenta a El Chambas como una herramienta de apoyo para conectar lo que una oferta pide con la evidencia que la persona puede demostrar. La decisión final y el envío siguen siendo de la persona.

## Evaluación interna de aceptación

| Criterio | Resultado |
|---|---:|
| Mensaje y mecanismo | 19/20 |
| Copy, confianza y CTA | 18/20 |
| Dirección visual y jerarquía | 18/20 |
| UX, responsive y accesibilidad | 14/15 |
| SEO y robustez técnica | 10/10 |
| **Total** | **79/85 = 92/100** |

La puntuación supera el umbral solicitado de 85/100. Es una revisión heurística de producto, no una promesa de conversión; debe complementarse con analítica y feedback de usuarios reales.

## Iteración aplicada

- El hero explica la promesa y el mecanismo en lenguaje directo.
- El video de 60 segundos aparece antes del detalle del método.
- El CTA de producto apunta a `https://agente.elchambas.com/`, donde vive el agente en Railway.
- Se incorporaron skip link, foco visible, navegación semántica, `aria-label`, canonical, robots y sitemap.
- Se eliminó el ocultamiento por JavaScript de secciones fuera del viewport: el contenido permanece visible para crawlers, cargas rápidas y capturas de página completa.

## Puerta de calidad

- `npm test`: debe pasar localmente y en cada Pull Request.
- Merge a `main`: tests y despliegue automático a Vercel.
- La landing pública queda en `https://elchambas.com/`.
